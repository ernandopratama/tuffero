# Tuffero Bakery — Design System

## 1. Brand Direction
- **Brand personality:** Premium, modern, warm, elegant, and welcoming.
- **Visual direction:** Dark Chocolate & Champagne Gold.
- Prioritize product photography, clear product information, generous whitespace, and a simple shopping flow.
- Keep the original Tuffero logo artwork unchanged; website fonts do not replace the logo typography.

## 2. Color Palette

| Token | Color name | HEX | Intended use |
|---|---|---|---|
| `color-primary` | Dark Chocolate | `#2B1B14` | Header, footer, dark sections, headings on light backgrounds |
| `color-accent` | Champagne Gold | `#C6A15B` | Primary CTA buttons, selected icons, highlights, decorative accents |
| `color-background` | Warm Ivory | `#F6F0E5` | Main page background and content sections |
| `color-secondary` | Roasted Brown | `#6D4C3D` | Supporting text and secondary visual elements |
| `color-surface` | Pure White | `#FFFFFF` | Product cards, forms, checkout surfaces |
| `color-border` | Soft Border | `#E3D5C0` | Borders, dividers, and input outlines |

### Color usage rules
- Header and footer: `#2B1B14`.
- Main background: `#F6F0E5`.
- Primary CTA: `#C6A15B` with text `#2B1B14`.
- Headings on light backgrounds: `#2B1B14`.
- Body/supporting text: `#6D4C3D`.
- Product cards and form surfaces: `#FFFFFF`.
- Borders and dividers: `#E3D5C0`.
- Use gold sparingly; avoid making it the dominant background color.
- Check text contrast for accessibility. Avoid small gold text on dark brown when contrast is insufficient.
- Suggested visual balance: approximately 55% Warm Ivory, 30% Dark Chocolate, 10% Roasted Brown, and 5% Champagne Gold.

## 3. Typography

### Primary font — Manrope
Use Manrope for most interface and content text:
- Navigation: 500–600.
- Body and descriptions: 400.
- Product names: 500–600.
- Prices: 600–700.
- Buttons and form labels: 600–700.
- Main headings: 500–600.

Google Fonts: https://fonts.google.com/specimen/Manrope

### Accent font — Playfair Display Italic
Use Playfair Display Italic selectively for:
- A few italic words in the hero heading.
- Selected promotional headlines.
- Short taglines or editorial statements.

Avoid using the accent font for long paragraphs, product details, navigation, or checkout UI.

Google Fonts: https://fonts.google.com/specimen/Playfair+Display

### Recommended type scale

| Element | Desktop | Mobile |
|---|---:|---:|
| Hero heading | 52–64 px | 34–42 px |
| Section heading | 32–40 px | 26–32 px |
| Product name | 16–20 px | 16–18 px |
| Body text | 14–16 px | 14–16 px |
| Navigation | 14–16 px | 14–16 px |
| CTA button | 14–16 px | 14–16 px |
| Small label / eyebrow | 11–12 px | 11–12 px |

Use responsive sizing, comfortable line-height, and readable tap targets on mobile.

## 4. Component Styling

### Buttons
- Primary button background: `#C6A15B`.
- Primary button text: `#2B1B14`.
- Suggested hover background: `#D8B978`.
- Use clear labels such as “Jelajahi Produk”, “Tambah ke Keranjang”, and “Checkout”.
- Keep button shape and spacing consistent.

### Header and navigation
- Header may use Dark Chocolate (`#2B1B14`) with Warm Ivory (`#F6F0E5`) text.
- Use Champagne Gold (`#C6A15B`) for small brand accents or active states.
- Keep navigation uncluttered and responsive.

### Product cards
- Surface: Pure White (`#FFFFFF`) or Warm Ivory (`#F6F0E5`).
- Product photography should be the main focus.
- Use Dark Chocolate for product titles and Roasted Brown for supporting details.
- Use Champagne Gold for restrained badges or highlights.

### Hero section
- Use high-quality Tuffero product or bakery photography.
- Add a dark brown overlay for readable text over photos.
- Suggested overlay: `linear-gradient(rgba(43, 27, 20, 0.68), rgba(43, 27, 20, 0.80))`.
- Main heading: Manrope, with optional Playfair Display Italic on a few emphasized words.
- Primary CTA: Champagne Gold with Dark Chocolate text.
- Ensure the hero remains legible on mobile.

### Forms and checkout
- Form surfaces: Pure White (`#FFFFFF`).
- Text: Dark Chocolate (`#2B1B14`).
- Borders: Soft Border (`#E3D5C0`).
- Error and success states must use distinct, accessible status colors; do not rely on brand colors alone.

## 5. Image Direction
- Prefer authentic Tuffero product photography where available.
- Use warm, soft lighting and natural food textures.
- Avoid imagery that misrepresents actual products.
- Maintain consistent crop ratios and quality across product cards.
- Optimize image sizes and responsive loading.

## 6. Implementation Notes
- Intended stack: Laravel Blade, Tailwind CSS, and Alpine.js for lightweight interactions.
- Use CSS variables or Tailwind theme tokens for consistent colors.
- Load fonts from Google Fonts during development; consider self-hosting for production if appropriate for performance and privacy.
- Do not use website typography to redraw or replace the official logo.
- Validate responsive behavior, keyboard focus, and text contrast before release.

```css
  --font-heading: "Manrope", sans-serif;
  --font-accent: "Playfair Display", Georgia, serif;

```

## 8. Font Loading Example

Add this to the main Blade layout `<head>` if using Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=Playfair+Display:ital,wght@1,400;1,500;1,600&display=swap" rel="stylesheet">
```

## 9. Design Acceptance Checklist
- [ ] The approved color palette is used consistently.
- [ ] Manrope is the primary font; Playfair Display Italic is used only as an accent.
- [ ] Gold is used selectively and primary button text remains legible.
- [ ] Product photography reflects actual Tuffero products.
- [ ] Layout is responsive across desktop, tablet, and mobile.
- [ ] Keyboard focus states are visible.
- [ ] Text contrast is checked for accessibility.
- [ ] Product, cart, and checkout interfaces remain clear and easy to use.
